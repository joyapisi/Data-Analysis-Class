# Data Fundamentals Group Work

Title: Data Analysts at Work — Visualising Data

NOTE: BEFORE STARTING, PLEASE GO THROUGH THIS [SERIES OF QUESTIONS WITH YOUR GROUP MEMBERS](https://github.com/joyapisi/Data-Analysis-Class/blob/main/INTRODUCTION.md)

Groups of 3–5 students · Practical project

### Student task

1. Use R to summarize GDP trends across selected countries in Africa.
6. Create at least **two visualizations** using `ggplot2`, one must be a time-series line chart.
8. Present recommendations or conclusions supported by the data.

### Marking rubric

| Criterion                           | points |
| ----------------------------------- | ----- |
| Dataset selection and understanding | 4     |
| Correct R analysis and summaries    | 4     |
| Visualizations using ggplot2        | 4     |
| Interpretation and presentation     | 3     |
| Total                               | 15    |

Deliverables: R script or R Markdown file, dataset source, two visualizations, and a short report of findings.
