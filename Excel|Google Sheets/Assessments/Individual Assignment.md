## Individual assignment — 10 marks

Title: Spreadsheet Data Quality Challenge

Individual practical · Suggested duration: 45–60 minutes

### Scenario

You have been given a student registration CSV file containing these columns:

`Student_ID, Student_Name, Course, Age, Registration_Date, Fees_Paid, Email`

The file contains:

- Duplicate student IDs.
- Names with inconsistent capitalization and extra spaces.
- Ages stored as text.
- Dates in inconsistent formats.
- Blank email addresses.
- Negative fees and invalid age values.

### Tasks and marking scheme

| Task                                                    | Marks |
| ------------------------------------------------------- | ----- |
| Import the CSV and identify incorrect data types        | 2     |
| Remove duplicates and clean names                       | 2     |
| Correct date, age and fee formats                       | 2     |
| Apply data validation to age, fees or course            | 2     |
| Filter invalid records and submit the corrected dataset | 2     |
| Total                                                   | 10    |

Students must submit the corrected spreadsheet and demonstrate at least two data validation rules.

Assessment rule: Marks are awarded for correctly applying the tools and producing valid results, not simply for presenting a finished spreadsheet.
