# Excel & Google Sheets: Continuous Assessment Plan

Course focus: Data preparation, validation, and cleaning using Microsoft Excel and Google Sheets.

 ## CAT I and CAT II — 30 marks

PART I: Data Types, CSV and Data Validation

Suggested duration: 30–40 minutes

- Identify the correct data type for five given fields. (3 marks)
- Import a CSV file and explain why some values may be misinterpreted. (3 marks)
- Identify and correct incorrectly formatted numbers and dates. (3 marks)
- Create a dropdown list for a course or department column. (3 marks)
- Set a numeric validation rule and test an invalid entry. (3 marks)

PART II: Practical Data Cleaning and Standardization

Suggested duration: 40–50 minutes

- Identify and remove duplicate records. (3 marks)
- Handle blank cells using an appropriate documented method. (3 marks)
- Standardize text, date and number formats. (3 marks)
- Sort and filter the cleaned records to find specified entries. (3 marks)
- Verify the cleaned dataset and explain the corrections made. (3 marks)

## 6.  datasets

**Group assignment: Retail sales records**

Columns: Transaction_ID, Branch, Product, Quantity, Unit_Price, Sale_Date, Payment_Method.

Focus: Duplicates, missing data, inconsistent product names, dates and prices.


**Individual assignment: Student registration**

Columns: Student_ID, Student_Name, Course, Age, Registration_Date, Fees_Paid, Email.

Focus: Data types, text cleaning, duplicates and validation rules.


**CAT datasets: Employee attendance**
Columns: Employee_ID, Employee_Name, Department, Attendance_Date, Check_In, Hours_Worked.

Focus: Unfamiliar records, date and time formats, missing entries, sorting and filtering.


This assessment structure evaluates practical spreadsheet competence, data quality awareness and independent problem-solving across the topics already covered.
