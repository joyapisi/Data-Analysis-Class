# Excel & Google Sheets: Continuous Assessment Plan

Course focus: Data preparation, validation, and cleaning using Microsoft Excel and Google Sheets.


## 2. Group assignment — 15 marks

Title: Cleaning and Validating a Business Dataset

Groups of 3–5 students · Practical project

Scenario: A Kenyan retail business has collected sales records from several branches. The CSV file contains duplicate transactions, blank cells, inconsistent dates, incorrectly formatted prices, invalid quantities and inconsistent product names. Your team has been hired to prepare the data for analysis.

### Student tasks

1. Import the supplied CSV file into Excel or Google Sheets.
2. Identify and remove duplicate transactions.
3. Identify missing values and document how they are handled.
4. Correct inconsistent product names and text formatting.
5. Correct data types, including dates, quantities and prices.
6. Apply data validation to restrict invalid entries.
7. Sort and filter the cleaned records.
8. Submit the original dataset, cleaned dataset and a short cleaning report.

### Marking rubric

| Criterion                                           | Marks |
| --------------------------------------------------- | ----- |
| Correct CSV import and identification of data types | 2     |
| Duplicate removal and missing-value handling        | 3     |
| Correction of inconsistent data and formats         | 3     |
| Appropriate data validation rules                   | 3     |
| Sorting, filtering and verification                 | 2     |
| Documentation and group presentation                | 2     |
| Total                                               | 15    |

Deliverables: Original CSV, cleaned spreadsheet, validation rules and a brief report describing the problems found and corrected.

## 3. Individual assignment — 10 marks

Title: Spreadsheet Data Quality Challenge

Individual practical · Suggested duration: 45–60 minutes

### Scenario

You have been given a student registration CSV file containing these columns:

`Student_ID, Student_Name, Course, Age, Registration_Date, Fees_Paid, Email`

The file contains:

- Duplicate student IDs.
- Names with inconsistent capitalization and extra spaces.
- Ages stored as text.
- Dates in inconsistent formats.
- Blank email addresses.
- Negative fees and invalid age values.

### Tasks and marking scheme

| Task                                                    | Marks |
| ------------------------------------------------------- | ----- |
| Import the CSV and identify incorrect data types        | 2     |
| Remove duplicates and clean names                       | 2     |
| Correct date, age and fee formats                       | 2     |
| Apply data validation to age, fees or course            | 2     |
| Filter invalid records and submit the corrected dataset | 2     |
| Total                                                   | 10    |

Students must submit the corrected spreadsheet and demonstrate at least two data validation rules.

Assessment rule: Marks are awarded for correctly applying the tools and producing valid results, not simply for presenting a finished spreadsheet.

## 4. CAT I and CAT II — 30 marks

Suggested duration: 30–40 minutes

- Create a dropdown list for a course or department column. (3 marks)
- Set a numeric validation rule and test an invalid entry. (3 marks)
