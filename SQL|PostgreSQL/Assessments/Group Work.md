## Group assignment — 15 points

NOTE: BEFORE STARTING, PLEASE GO THROUGH THIS [SERIES OF QUESTIONS WITH YOUR GROUP MEMBERS](https://github.com/joyapisi/Data-Analysis-Class/blob/main/INTRODUCTION.md)

Title: Design and Manage a Student Registration Database Using PostgreSQL

Mode: Groups of 3–5 students · Practical project

### Scenario

The African Digital Media Institute (ADMI) wants a database to manage students registering for courses. The administration needs to store student details, course information, and registration records. Your group has been hired to develop a basic PostgreSQL database that supports these activities.

### Student tasks

1. Create a database named `admi_registration`.
2. Create the following tables: `students`, `courses` and `registrations`.
3. Insert at least 10 student records, 5 courses and 15 registration records.
4. Demonstrate all CRUD operations using SQL queries I.E:
- Retrieve and display all students and all available courses.
- Find students registered for a particular course.
- Update a student's details or change a course registration status.
- Delete a specified registration record.

### Marking rubric

| Assessment criterion                              | points |
| ------------------------------------------------- | ----- |
| Database and table creation                       | 3     |
| Inserting records (Create)                        | 3     |
| Retrieving records (Read)                         | 3     |
| Updating records (Update)                         | 2     |
| Deleting records (Delete)                         | 2     |
| SQL statements, evidence, and group presentation  | 2     |
| Total                                             | 15    |

### Deliverables

- SQL statements containing all database commands.
- Screenshots showing successful execution of the queries.
- A short demonstration by the group, with each member explaining at least one query.

Learning outcome: Students demonstrate how CRUD operations work together in a realistic database application.
