# SQL and PostgreSQL ASSIGNMENTS

## Individual assignment — 10 points

Title: SQL CRUD Skills Challenge

Mode: Individual · Practical lab assignment

### Scenario

A small stationery shop needs a database to manage its inventory. Create a PostgreSQL database named `stationery_shop` and a table named `products`.

The table should contain:

- `product_id` — integer, primary key
- `product_name` — text
- `category` — text
- `quantity` — integer
- `unit_price` — numeric

### Tasks

1. Create the `products` table with the appropriate data types and primary key. (2 points)
2. Insert five products into the table. (2 points)
3. Retrieve all products and display products with a quantity below 10. (2 points)
4. Update the price of one product and increase its stock quantity. (4 points)


Total: 10 points

### Submission requirements

Submit the `sql` statements containing the queries in the order they were executed. Include screenshots of the results for the `SELECT` statements.

Assessment rule: Each query must execute successfully and produce the intended result. Students should not submit screenshots without the SQL commands used.
